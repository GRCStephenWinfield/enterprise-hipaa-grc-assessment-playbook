# 13 – Cloud Security

> **Enterprise Cybersecurity Governance, Risk & Compliance (GRC) Assessment Portfolio**

The Cloud Security domain evaluates the organization's ability to securely govern, configure, monitor, protect, and recover cloud-hosted services and workloads across Infrastructure-as-a-Service (IaaS), Platform-as-a-Service (PaaS), Software-as-a-Service (SaaS), containers, Kubernetes, and serverless environments.

This assessment examines cloud governance, identity management, network security, encryption, cloud posture management, workload protection, Kubernetes security, logging, backup and recovery, Infrastructure as Code (IaC), SaaS governance, cloud incident response, and continuous improvement.

---

# Purpose

The purpose of this assessment is to determine whether cloud environments are securely designed, governed, monitored, and operated in accordance with cybersecurity best practices and regulatory requirements.

The assessment evaluates:

- Cloud Security Governance
- Landing Zones & Guardrails
- Cloud IAM & Privileged Access
- Cloud Network Security
- Encryption, Keys & Secrets
- Cloud Security Posture Management (CSPM)
- Workload Protection
- Kubernetes Security
- Serverless & API Security
- Cloud Logging & Monitoring
- Backup & Recovery
- Infrastructure as Code
- SaaS Governance
- Cloud Incident Response
- Continuous Improvement
