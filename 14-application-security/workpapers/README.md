# Application Security Workpaper Library

> **Phase 14 – Application Security**

This folder contains the detailed technical workpapers supporting the Application Security assessment.

Each workpaper documents the control objective, framework mapping, evidence requirements, testing procedures, observations, findings, maturity assessment, and conclusions for a specific Application Security capability.
