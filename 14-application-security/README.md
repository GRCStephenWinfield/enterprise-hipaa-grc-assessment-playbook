# 14 – Application Security

> **Enterprise Cybersecurity Governance, Risk & Compliance (GRC) Assessment Portfolio**

The Application Security domain evaluates the organization's ability to design, develop, test, deploy, and maintain secure software throughout the Secure Software Development Lifecycle (SSDLC).

This assessment examines application security governance, secure architecture, secure coding, application security testing, software composition analysis, software supply chain security, API security, mobile application security, penetration testing, remediation management, and continuous improvement.

---

# Purpose

The purpose of this assessment is to determine whether application development and DevSecOps practices effectively reduce software vulnerabilities while supporting secure software delivery and regulatory compliance.

The assessment evaluates:

- Application Security Governance
- Secure Software Development Lifecycle (SSDLC)
- Threat Modeling
- Secure Architecture
- Secure Coding
- Code Review
- Static Application Security Testing (SAST)
- Dynamic & Interactive Application Security Testing (DAST/IAST)
- Software Composition Analysis (SCA)
- Software Bill of Materials (SBOM)
- Secrets & Cryptographic Material Management
- CI/CD Pipeline Security
- Software Supply Chain Security
- Authentication & Authorization
- API Security
- Mobile Application Security
- Penetration Testing
- Vulnerability Remediation
- Continuous Improvement
