# 10 – Configuration & Change Management

> **Enterprise Cybersecurity Governance, Risk & Compliance (GRC) Assessment Portfolio**

The Configuration & Change Management domain evaluates the organization's ability to establish secure configuration baselines, manage infrastructure and application changes, detect unauthorized modifications, maintain configuration integrity, and continuously improve operational resilience.

This assessment examines configuration governance, secure baselines, change management processes, infrastructure-as-code, cloud configuration management, endpoint and server configuration, network device configuration, configuration monitoring, exception management, and continuous improvement.

---

# Purpose

The purpose of this assessment is to determine whether configuration and change management processes effectively protect enterprise systems from unauthorized changes, configuration drift, operational disruption, and security vulnerabilities.

The assessment evaluates:

- Configuration Governance
- Secure Configuration Baselines
- System Hardening Standards
- Change Governance
- Standard Change Management
- Emergency Change Management
- Configuration Drift Detection
- Infrastructure as Code
- Policy as Code
- Cloud Configuration Management
- Network Device Configuration
- Database Configuration
- Endpoint & Server Configuration
- Configuration Monitoring
- Configuration Exceptions
- Continuous Improvement
