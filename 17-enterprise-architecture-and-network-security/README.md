# 17 – Enterprise Architecture & Network Security

> **Enterprise Cybersecurity Governance, Risk & Compliance (GRC) Assessment Portfolio**

The Enterprise Architecture & Network Security (EANS) domain evaluates the organization's ability to design, implement, secure, monitor, and continuously improve enterprise network architecture and connectivity while supporting Zero Trust principles, cloud integration, resiliency, and business objectives.

This assessment examines enterprise architecture governance, network segmentation, Zero Trust, perimeter security, SD-WAN, SASE, wireless security, DNS security, network monitoring, hybrid cloud networking, device hardening, resiliency, and continuous improvement.

---

# Purpose

The purpose of this assessment is to determine whether enterprise architecture and network infrastructure provide secure, resilient, scalable, and well-governed connectivity that supports organizational objectives while minimizing cybersecurity risk.

The assessment evaluates:

- Enterprise Architecture Governance
- Current-State Architecture
- Target-State Architecture
- Reference Architecture
- Network Segmentation
- Trust Zones
- Firewalls
- Proxies
- Egress Controls
- NAC
- Microsegmentation
- Zero Trust Network Access
- VPN Security
- Wireless Security
- DNS / DHCP / IPAM
- Routing & Switching
- Network Resiliency
- SD-WAN
- SASE
- Hybrid Cloud Connectivity
- Third-Party Connectivity
- Network Monitoring
- Device Hardening
- Asset Lifecycle
- Continuous Improvement
