# 08 – Security Monitoring & Incident Response

> **Enterprise Cybersecurity Governance, Risk & Compliance (GRC) Assessment Portfolio**

The Security Monitoring & Incident Response (SMIR) domain evaluates the organization's ability to continuously monitor security events, detect malicious activity, investigate incidents, coordinate response efforts, preserve evidence, and recover from cybersecurity events.

This assessment examines Security Operations Center (SOC) governance, SIEM configuration, log management, threat detection, digital forensics, threat intelligence, SOAR automation, EDR/XDR, cloud security monitoring, executive reporting, and continuous improvement.

---

# Purpose

The purpose of this assessment is to determine whether the organization has implemented an effective security monitoring and incident response capability capable of detecting, responding to, containing, recovering from, and learning from cybersecurity incidents.

The assessment evaluates:

- Security Operations Center (SOC)
- SIEM Governance
- Log Collection & Retention
- Security Alert Management
- Detection Engineering
- Incident Response Program
- Digital Forensics
- Threat Intelligence
- Threat Hunting
- UEBA
- Identity Threat Detection
- SOAR
- Malware & Ransomware Response
- Cloud Security Monitoring
- EDR / XDR
- Executive Reporting
- Continuous Improvement
