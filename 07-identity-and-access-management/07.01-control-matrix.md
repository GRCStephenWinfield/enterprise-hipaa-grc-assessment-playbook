# Purpose

This Control Matrix defines the Identity & Access Management controls included within the assessment scope.

The matrix establishes control objectives, ownership, framework mappings, testing methods, expected evidence, and associated technical workpapers to ensure consistent assessment execution.

# Assessment Methods

The following assessment methods will be used throughout the IAM domain:

- Policy and procedure review
- Identity governance review
- Configuration review
- Technical testing
- User account sampling
- Role assignment validation
- Privileged account testing
- Authentication testing
- MFA validation
- Log review
- Evidence inspection
- Personnel interviews
