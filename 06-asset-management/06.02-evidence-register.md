# Purpose

This Evidence Register identifies all documentation required to support the Asset Management assessment.

Each evidence item is uniquely identified and mapped to the appropriate Asset Management controls. Evidence collected during the assessment will be used to validate implementation, verify compliance, and support assessment conclusions.

# Evidence Collection Requirements

Evidence should:

- Be current and approved.
- Cover the defined assessment period.
- Be complete and unaltered.
- Be obtained from authoritative sources.
- Be retained in accordance with organizational policy.

---

# Evidence Validation

The assessor should verify that evidence:

- Is complete.
- Is accurate.
- Is current.
- Supports the control objective.
- Is approved where required.
- Can be independently validated.

---

# Evidence Sources

Primary evidence sources include:

- Configuration Management Database (CMDB)
- Enterprise Asset Management System
- Cloud Management Platforms
- Endpoint Management Tools
- Vulnerability Management Platforms
- IT Service Management (ITSM) Platform
- Procurement System
- Clinical Engineering System
- Security Information and Event Management (SIEM)
- Internal Audit Repository

# Evidence Retention

Assessment evidence should include:

- Version history

- Collection date
- Custodian
- Classification
- Supporting metadata
