# Purpose

This Control Matrix defines the control objectives evaluated during the Asset Management assessment.

Each control establishes the expected cybersecurity practices for identifying, inventorying, classifying, protecting, monitoring, maintaining, and securely disposing of enterprise information assets.

Each control maps to applicable regulatory requirements and industry frameworks to support consistent testing and reporting.

# Control Testing Strategy

Each control will be evaluated through:

- Documentation review
- Evidence validation
- Personnel interviews
- Sample testing
- Technical verification
- Gap analysis
- Risk evaluation

---

# Testing Objectives

For every control, the assessment will determine whether:

- Policies and procedures are documented.
- Roles and responsibilities are assigned.
- Processes are consistently implemented.
- Supporting evidence exists.
- Regulatory requirements are met.
- Risks are appropriately managed.
- Continuous monitoring occurs.

---

# Control Ratings

| Rating | Definition |
|---------|------------|
| Effective | Control is fully implemented and operating effectively. |
| Partially Effective | Control exists but requires improvement. |
| Ineffective | Control is missing or ineffective. |
| Not Applicable | Control does not apply to the assessed environment. |
