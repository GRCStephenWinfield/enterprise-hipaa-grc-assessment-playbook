# Root Cause Analysis

Common contributing factors include:

- Manual inventory reconciliation activities.
- Inconsistent documentation practices.
- Limited automation across cloud and CMDB integrations.
- Evolving SaaS and AI usage.
- Resource constraints affecting periodic reviews.
- Delayed lifecycle updates.
- Inconsistent executive performance reporting.

---

# Overall Assessment

Overall Asset Management effectiveness is assessed as:

**Partially Effective**

The organization maintains a mature Asset Management program with well-defined governance processes. Most findings represent opportunities to improve automation, consistency, and governance rather than fundamental control failures.

---

# Recommended Priorities

## Immediate (0–30 Days)

- Address unsupported medical device firmware.
- Improve Shadow IT monitoring.
- Review unsupported software inventory.

## Short-Term (30–90 Days)

- Improve CMDB reconciliation.
- Complete ownership assignments.
- Improve configuration governance.
- Review asset classifications.

## Long-Term (90–180 Days)

- Enhance KPI reporting.
- Improve lifecycle automation.
- Increase cloud inventory automation.
- Strengthen asset-risk integration.
