# Purpose

This Plan of Action & Milestones (POA&M) documents the corrective actions required to remediate findings identified during the Asset Management assessment.

Each action item includes ownership, implementation milestones, dependencies, validation criteria, estimated completion dates, and implementation status.

The POA&M serves as the authoritative management tracking document for remediation activities.

# Implementation Milestones

## Phase 1 — Immediate (0–30 Days)

- Upgrade unsupported medical device firmware.
- Validate vendor support agreements.
- Review high-risk software inventory.

---

## Phase 2 — Near-Term (30–90 Days)

- Expand Shadow IT monitoring.
- Complete ownership assignments.

- Improve cloud governance.

- Improve software license optimization.

# Dependencies

Major dependencies include:

- CMDB modernization
- Asset discovery automation
- Cloud governance improvements
- Vendor coordination
- Medical device maintenance schedules
- Executive governance meetings
- Budget approval
- Change management activities

---

# Validation Criteria

Each corrective action should be considered complete when:

- Supporting documentation has been updated.
- Evidence has been collected.
- Control effectiveness has been validated.
- Internal Audit has confirmed implementation (where applicable).
- Management has formally accepted completion.
- Associated risks have been reduced to acceptable levels.
