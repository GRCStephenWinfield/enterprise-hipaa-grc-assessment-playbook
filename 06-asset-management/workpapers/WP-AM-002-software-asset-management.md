# Purpose

This workpaper evaluates whether Magnolia Regional Medical Center maintains a complete, accurate, and continuously updated inventory of authorized software assets.

The assessment determines whether software assets are approved, inventoried, licensed, monitored, maintained, and removed throughout their lifecycle to support cybersecurity, operational resilience, and regulatory compliance.

---

# Control Objective

Determine whether the organization:

- Maintains a complete software inventory.
- Identifies unauthorized software.
- Tracks software versions.
- Manages software licensing.
- Defines approved software standards.
- Removes unsupported software.
- Supports vulnerability and patch management through accurate software records.

# Risks Addressed

Failure to maintain an accurate software inventory may result in:

- Unauthorized software installations.
- Unsupported software remaining in production.
- Licensing violations.
- Increased malware exposure.
- Missed security updates.
- Software supply chain risks.
- Increased attack surface.
- Regulatory noncompliance.

# Evaluation Criteria

### Effective

- Complete software inventory.
- Approved software catalog maintained.
- Accurate version tracking.
- Licensing managed.
- Unsupported software identified.
- Continuous software discovery implemented.

### Partially Effective

- Inventory maintained.
- Minor software gaps.
- Some licensing inconsistencies.
- Limited discovery automation.

### Ineffective

- Incomplete software inventory.
- Unauthorized software common.
- Licensing unmanaged.
- Unsupported software widespread.
- No software governance.
