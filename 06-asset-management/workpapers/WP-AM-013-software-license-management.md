# Purpose

This workpaper evaluates whether Magnolia Regional Medical Center effectively manages software licensing, subscription renewals, software entitlements, and vendor compliance across enterprise, clinical, and cloud environments.

The assessment determines whether software licensing supports operational continuity, regulatory compliance, cybersecurity, and financial stewardship.

---

# Control Objective

Determine whether the organization:

- Maintains an accurate software license inventory.
- Tracks software entitlements.
- Monitors software utilization.
- Reviews software license compliance.
- Manages subscription renewals.
- Governs open-source software usage.
- Supports software lifecycle management.

# Risks Addressed

Failure to effectively manage software licenses may result in:

- Vendor licensing violations.
- Unsupported software.
- Missed security updates.
- Unexpected renewal costs.
- Unauthorized software usage.
- Audit findings.
- Legal liability.
- Increased cybersecurity risk.

# Evaluation Criteria

### Effective

- Complete license inventory.
- Compliance regularly reviewed.
- Renewals proactively managed.
- Open-source governance implemented.
- Software utilization optimized.

### Partially Effective

- License inventory maintained.
- Minor compliance gaps.
- Renewals inconsistently tracked.
- Limited utilization analysis.

### Ineffective

- License inventory incomplete.
- Compliance unmanaged.
- Renewals missed.
- Open-source software uncontrolled.
- Significant licensing exposure.
