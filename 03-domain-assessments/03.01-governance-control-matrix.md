# Purpose

The Governance Control Matrix is the master planning and assessment document for the Governance Domain.

It establishes every governance control evaluated during the assessment and provides complete traceability between regulatory requirements, framework mappings, evidence, interviews, workpapers, findings, risks, recommendations, and remediation activities.

This matrix serves as the authoritative index for all Governance assessment activities.

---

# Assessment Objectives

The Governance Control Matrix supports the following objectives:

- Identify all governance controls within assessment scope.
- Map each control to applicable regulatory and industry frameworks.
- Assign ownership and accountability.
- Define testing procedures.
- Identify required evidence.
- Establish workpaper references.
- Enable traceability throughout the engagement.
- Support executive reporting and audit defensibility.

# Control Effectiveness Ratings

Each control will receive one of the following ratings after testing.

| Rating | Meaning |
|---------|---------|
| Effective | Control is properly designed, implemented, and operating effectively. |
| Partially Effective | Control exists but contains deficiencies. |
| Ineffective | Control does not adequately manage the identified risk. |
| Not Tested | Assessment limitation prevented testing. |
| Not Applicable | Control is outside the approved scope. |

# Consultant Notes

## Best Practices

- Maintain one authoritative control inventory.
- Assign a unique Control ID that never changes.
- Link every control to evidence before testing begins.
- Update the matrix immediately after testing.
- Use this matrix as the starting point for all Governance workpapers.

## Common Pitfalls

- Creating duplicate control IDs.
- Losing traceability between controls and findings.
- Mapping controls to only one framework when multiple apply.
- Updating workpapers without updating the matrix.

## Red Flags

- Controls without assigned owners.
- Controls lacking evidence references.
- Framework mappings that cannot be justified.
- Findings that cannot be traced back to a specific control.
- Workpapers that reference nonexistent Control IDs.
