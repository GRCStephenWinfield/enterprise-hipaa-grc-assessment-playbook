# Purpose

This document establishes the document numbering convention used throughout the Enterprise HIPAA Cybersecurity Assessment Playbook.

A consistent numbering standard ensures every document appears in the correct order within GitHub, supports efficient navigation, and clearly communicates where each document belongs within the overall assessment methodology.

# Folder Numbering Standard

Each major phase of the assessment is assigned a two-digit folder number.

Example:

```text
00-start-here
01-client-engagement
02-assessment-planning
03-enterprise-governance
...
29-executive-and-board-reporting
30-appendices-templates-and-references
```

Folders shall always be listed in numerical order.

---

# Document Numbering Standard

Every document begins with the folder number followed by a sequential document number.

Example:

```text
03.01-domain-overview.md
03.02-assessment-objectives.md
03.03-assessment-scope.md
03.04-framework-and-control-mapping.md
```

This numbering indicates both the assessment phase and the document's position within that phase.

---

# File Naming Convention

All filenames shall:

- Use lowercase letters
- Use hyphens instead of spaces
- Begin with the document number
- Use descriptive names
- End with the `.md` extension

Correct example:

```text
07.08-assessment-checklist.md
```

Incorrect examples:

```text
Assessment Checklist.md

Assessment_Checklist.md

assessment checklist.md

checklist.md
```

---

# Numbering Rules

Document numbers shall:

- Begin with `.01`
- Increase sequentially
- Never skip numbers without documented justification
- Never reuse retired document numbers
- Remain stable once published

The numbering standard provides:

- Consistent organization
- Easier cross-referencing
- Better version control
- Professional repository structure
