# Purpose

This document explains how to navigate the Enterprise HIPAA Cybersecurity Assessment Playbook.

The repository has been organized to mirror the lifecycle of a professional cybersecurity assessment. Each folder represents a major phase of the engagement, and each document builds upon the outputs of previous activities.

Following the repository in numerical order ensures assessments are performed consistently, evidence is collected before conclusions are reached, and executive reporting is based on validated results.

# Numbering Convention

Each folder is numbered sequentially.

Example:

```text
03-enterprise-governance
```

Each document within the folder is also numbered.

Example:

```text
03.01-domain-overview.md

03.02-assessment-objectives.md

03.03-assessment-scope.md
```

This numbering ensures GitHub displays documents in the same sequence they should be completed.

---

# Navigation Rules

Always begin with the README for each folder.

Next, complete each numbered document in ascending order.

Do not skip documents unless they are explicitly marked as **Not Applicable**.

Do not begin a new phase until the current phase is complete.

Each document identifies:

- Previous document
- Current document
- Next document
- Assessment progress
